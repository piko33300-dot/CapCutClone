# CapCutClone

Starter Android project inspired by CapCut.

## What it includes
- Home screen with a new project button
- Simple video editing screen
- Material UI styling
- Kotlin project structure ready for expansion

## How to run
1. Open Android Studio.
2. Choose `File -> Open` and select this folder.
3. Wait for Gradle sync.
4. Run the app on an emulator or Android device.
